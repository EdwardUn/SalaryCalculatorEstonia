# Salary Calculator Estonia

Простой Android-калькулятор зарплаты для плавающего графика в Эстонии.

## v0.1.0

- оклад brutto;
- норма часов;
- фактически отработанные часы;
- дополнительные начисления brutto;
- коэффициент оплаты сверхурочных;
- maksuvaba tulu;
- II sammas: нет / 2% / 4% / 6%;
- расчёт brutto и netto;
- сохранение истории по месяцам на телефоне;
- редактирование и удаление сохранённых месяцев;
- необязательное поле фактически полученной суммы и разница с расчётом.

### Налоговые значения по умолчанию для 2026

- tulumaks: 22%;
- maksuvaba tulu: 700 €/месяц;
- töötuskindlustus работника: 1,6%;
- II sammas выбирается пользователем.

> Важно: приложение — личный калькулятор, а не бухгалтерская или юридическая система. При суммированном учёте рабочего времени фактическое определение сверхурочных может зависеть от расчётного периода и условий трудового договора.

## Сборка через GitHub Actions

После push в `main` открой **Actions → Build Android APK → Artifacts** и скачай `SalaryCalculatorEstonia-debug`.
