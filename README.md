# Salary Calculator Estonia

Простой локальный Android-калькулятор зарплаты и месячных расходов для Эстонии.

## v0.2.0

### Зарплата
- оклад brutto;
- норма и фактически отработанные часы;
- дополнительные начисления brutto;
- коэффициент сверхурочных;
- редактируемые `tulumaks`, `maksuvaba tulu` и `töötuskindlustus`;
- II sammas: 0 / 2% / 4% / 6%;
- расчёт brutto/netto;
- история месяцев, редактирование и удаление;
- фактически полученная сумма и разница с расчётом;
- старые сохранённые месяцы продолжают открываться, для них применяются прежние значения 22% и 1,6%, если ставок ещё не было в записи.

### Расходы
- отдельная вкладка «Расходы»;
- расходы по месяцу и году;
- название, категория и сумма;
- категории: кредит, жильё, связь, еда, транспорт, подписка, страховка, другое;
- отметка «оплачено / не оплачено»;
- редактирование и удаление;
- итоги: всего, оплачено, осталось оплатить;
- если за тот же месяц сохранена зарплата, приложение показывает остаток после всех расходов.

Данные хранятся локально на телефоне в SharedPreferences. Сервер и регистрация не нужны.

> Приложение — личный калькулятор, не бухгалтерская или юридическая система. При суммированном учёте рабочего времени фактическое определение сверхурочных может зависеть от расчётного периода и условий трудового договора.

## Сборка через GitHub Actions

После push в `main` открой **Actions → Build Android APK → Artifacts** и скачай `SalaryCalculatorEstonia-debug`.
